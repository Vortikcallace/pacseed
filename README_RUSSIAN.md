# E-pacseed

E-pacseed — это декларативный инструмент для сборки и восстановления системы для Arch Linux. Он позволяет пользователям описывать целевое состояние системы (пакеты из официальных репозиториев и AUR) в простом YAML-манифесте, а затем применять это состояние на любой машине без ручного вмешательства. Он устраняет расхождения в конфигурации и делает воспроизводимость системы простой.

## Предварительные требования

Для сборки проекта необходимо иметь установленный Go. Кроме того, поскольку инструмент взаимодействует с системными пакетами, для корректной работы функции восстановления требуются pacman, git и base-devel.

## Сборка

Чтобы скомпилировать проект, выполните:
```
make build
```
Это создаст исполняемый бинарный файл в каталоге bin/.

Чтобы очистить скомпилированные бинарные файлы, выполните:
```
make clean
```
## Использование

После успешной сборки вы можете использовать инструмент из терминала:
```
sudo cp ./bin/pacseed /usr/local/bin/pacseed
```
После этого вы можете использовать pacseed из терминала:
```
pacseed [command]
```

### Команды

*   **`compile`**
    Сканирует ваши текущие установленные пакеты и генерирует YAML-манифест.
        ```
        pacseed compile --path "path/to/save" --name "my-config"
        ```
    *(Если `--path` не указан, файл сохраняется в ваш домашний каталог. Если `--name` не указан, по умолчанию используется `repos`.)*

*   **`restore`**
    Читает указанный YAML-манифест и устанавливает все перечисленные пакеты. Он автоматически проверяет наличие AUR-хелпера (yay или paru) и предлагает установить его, если он отсутствует.
        ```
        pacseed restore --path "path/to/config" --name "my-config"
        ```
    *(Для этой команды обязательны и `--path`, и `--name`).*

*   **`check`**
    Проверяет файл конфигурации и предоставляет информацию о репозиториях, перечисленных в манифесте.
      ```
        pacseed check --name "repos" --path "/your full path/" --repos
        pacseed check --name "repos" --path "/your full path/" --aur
        pacseed check --name "repos" --path "/your full path/" --repo "package-name"
      ```
